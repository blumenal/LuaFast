# LuaFast

O LuaFast acabou ! Estou de saco cheio! Mas está aí a última versão.
Mas vou deixar aqui a última versão, essa versão contem a dll estável.
Se você usa o extintores vá até a pasta da Steam, e apague a hid.dll e quando você abrir o LuaFast ele irá recriar a dll.

Essa DLL se mantém estável mesmo com as variações de quedas dos servidores do Steam Tools.

Observação sempre que você abre o Steam Tools ele apaga a DLL do LuaFast e coloca na pasta outra DLL então escolha usar o LuaFast ou Steam Tools.
